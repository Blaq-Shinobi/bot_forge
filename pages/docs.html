Getting started

Four steps take you from nothing to a live bot:

  1. Create a free BotForge account.
  2. Get a bot token from Telegram's @BotFather (see below).
  3. Open the Bot Builder and configure how your bot responds.
  4. Click Save & Deploy - your bot goes live immediately.

No server setup, no code. BotForge runs your bot for you.

Connecting a bot

Every Telegram bot needs a token from Telegram itself before anyone else can configure it:

  1. Open Telegram and message @BotFather.
  2. Send /newbot and follow the prompts for a name and username (must end in "bot").
  3. BotFather replies with a token that looks like 123456:ABC-DEF1234....
  4. Paste that token into the BotFather Token field in the Bot Builder.

Keep this token private - anyone who has it can control your bot. If it ever leaks, message @BotFather and use /revoke to invalidate it, then generate a new one.

Commands

Commands are exact-match: a user has to type the command precisely (like /pricing) for your configured response to fire. Add as many as you like in the Builder's Commands tab - each one is just a command name and the text to reply with.

A few commands are special-cased for crypto/market templates: /price, /market, and /movers pull live data automatically instead of using static text (see Market-data bots below).

Auto-replies

Auto-replies fire on a keyword match anywhere in a user's message, not an exact match - if someone's message contains your trigger word, your reply goes out. Use these for things people might phrase many different ways, like mentioning "pricing" or "support" mid-sentence.

Commands are checked before auto-replies, so an exact command match always takes priority.

Welcome & fallback messages

The welcome message sends when someone says hi, hello, hey, or starts the bot for the first time. The fallback message sends when nothing else matches - your safety net so the bot never goes silent.

Scheduled messages

Pro and Business plans. Set a message and a time of day (hour and minute), and it goes out automatically every day at that time - useful for daily tips, reminders, or recurring updates.

Market-data bots

Templates like CryptoPulseBot (see Templates) give users live prices, market summaries, and sentiment readings pulled from public data sources.

⚠️

These bots share information, not financial advice. They can't place trades, connect to an exchange, or manage anyone's money - and nothing they say should be read as a recommendation to buy or sell. If you deploy a market-data bot, keep that distinction clear to your users.
